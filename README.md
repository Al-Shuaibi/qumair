رابط الطلاب: https://al-shuaibi.github.io/qumair/
رابط الطالبات: https://al-shuaibi.github.io/qumair/?section=female

## النسخة الحالية

مئة وعشرة أسئلة جاهزة. الإجابة تبدأ مختصرة، مع زر لقراءة النص الكامل وسماعه. رحلة المملكة تضم ستة فصول سردية مستقلة. المذنب مشهد بصري أثناء الانتظار، بلا صوت ولا مقاطعة للإجابات.

الصوت من ElevenLabs بمعرّف القسم المختار. معرّف الطلاب yXEnnEln9armDCyhkXcA، والطالبات VjxKp6w1MCufETfW5zFM. يستخدم توليد النصوص Eleven v4. صوت المحادثة المباشرة ونموذجها يحددهما Agent المنشور داخل ElevenLabs.

الأسئلة الجديدة تصل إلى ElevenAgents. معرّف الطلاب agent_1801m4m793rmetft16v107j4rsyb. لا توجد طلبات إلى Google. البحث المباشر في الإنترنت يحتاج أداة بحث مفعلة في Agent؛ مكتبة المعرفة وحدها لا تضيف بحثًا مباشرًا.

## إعداد ElevenLabs

استبدل ملف Knowledge Base بالنسخة agent-knowledge.txt. استبدل System prompt بمحتوى agent-system-prompt.txt، وFirst message بمحتوى agent-first-message.txt. فعّل interruption ضمن Advanced / Client Events، واسمح بمقاطعة First message، واضبط Turn eagerness إلى Eager إذا كان انتظار نهاية الكلام طويلًا. انشر التعديلات باستخدام Publish ثم اختبر مقاطعة فعلية أثناء الجواب. التعليمات النصية وحدها لا تفعل المقاطعة.

في الموقع افتح «الصوت»، وأدخل مفتاح ElevenLabs لتوليد الإجابات الجاهزة، ثم اختبر الصوت. لا يُحفظ المفتاح في GitHub أو على القرص؛ إعادة تحميل الصفحة تمسحه. للمحادثة الصوتية المباشرة فعّل خيار ElevenAgents، ولا يلزم إدخال مفتاح شخصي إذا كان Agent يسمح باتصال الموقع.

مساعد قُمَيرة مربوط افتراضيًا بالمعرّف agent_5701m4mdwvadep1ahx64btrx53g5، وصوتها Nouf. انشر إعداداته داخل ElevenLabs ثم اختبر المحادثة المباشرة النسائية. الصوت النسائي للنصوص الجاهزة مستقل ويستخدم معرّف الصوت المذكور أعلاه.

## التسجيلات

لم تُولّد مجموعة تسجيلات مشتركة بعد. يُحفظ صوت الإجابة المكتمل تلقائيًا على الجهاز الذي طلبه؛ هذه الذاكرة لا تنتقل تلقائيًا إلى جهاز آخر. تجهيز الأصوات الاختياري يقتصر على ثماني إجابات مهمة مختصرة والتعريف: تسعة مقاطع للقسم الحالي. لا يبدأ دون مفتاح واعتماد عينة. راجع رصيد الخدمة قبل استخدامه. لا يسجل المحادثات المباشرة.

recording-texts.zip يضم النصوص السردية الكاملة للصوتين، وهي تختلف عن الإجابات المختصرة الافتراضية. المقاطع المستوردة تُستخدم في وضع «مقاطع محفوظة». نشر مجموعة مشتركة يحتاج ملفات صوتية معتمدة وبيانًا يطابق النص والقسم والصوت؛ البيان الحالي لا يحتوي مجموعة مشتركة.

## التحقق

فحوص محلية للربط والإلغاء والمقاطعة اليدوية والملفات والنصوص، وفحص واجهة المتصفح. نجاحها لا يثبت جودة نطق كل إجابة أو نجاح المقاطعة الصوتية في حساب ElevenLabs. يلزم اختبار حساب المستخدم فعليًا، والتحقق من صلاحيات الميكروفون والرصيد على أجهزة العرض.
تحديث تشغيل الزوار: المحادثة المباشرة مفعلة افتراضيًا. دون مفتاح API، تُرسل القصص والإجابات الجاهزة إلى Agent القسم ليقرأها؛ تحتاج إذن الميكروفون واتصالًا ورصيد المحادثات. رحلة المملكة في هذا المسار فصل واحد في كل مرة، ثم زر الفصل التالي. تشغيل الصوت بالمفتاح والتسجيلات يبقى مسارًا اختياريًا للتجهيز.
