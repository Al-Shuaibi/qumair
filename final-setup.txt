إكمال إعداد قُمَير داخل ElevenLabs

1. في Agent الحالي، افتح صفحة Agent واستبدل System prompt بالكامل بالنص الموجود في qumair-agent-prompt.txt. لا تضفه فوق التعليمات القديمة؛ القديمة تطلب إجابات طويلة لكل سؤال.
2. استبدل First message بالنص القصير في agent-first-message.txt. أبقِ Interruptible مفعّلًا، أو ألغِ Disable first message interruptions إذا ظهر بهذا الاسم.
3. استبدل ملف Knowledge Base القديم بملف qumair-agent-knowledge.txt المراجع. ارفع نسخة واحدة فقط. داخل Retrieval، راجع إعداد RAG لتكون الاستعانة بالمقاطع ذات الصلة بدل وضع الملف الكبير كله في التعليمات؛ لا نغير هذا الإعداد دون رؤية خياراته الفعلية.
4. افتح Advanced ثم Client Events وفعّل interruption. في Turn eagerness اختر Eager إذا ظهر. لا تخلط ذلك مع Take turn after silence؛ الأخير يحدد متى يبادر المساعد بعد صمت طويل، وليس زمن التقاط السؤال.
5. اضغط Publish. داخل Preview اسأل سؤالًا، وأثناء الجواب قل: «توقف، سؤالي عن شاهين سات». تحقق أنه يوقف الجواب السابق ويجيب عن الجديد. يمكن تجربة سماعة مع ميكروفون لتقليل التقاط صوت السماعة والضوضاء.
6. لتفعيل المحادثة المباشرة في موقع الطلاب، افتح الصوت وفعّل «محادثة صوتية مباشرة». معرّف Agent موجود مسبقًا. احتفظ بصفحة الموقع مفتوحة للمحافظة على المفتاح في الذاكرة إن كنت تستخدم توليد الإجابات الجاهزة.
7. لقُمَيرة: يلزم Agent مستقل بالصوت النسائي المختار وتعريف مؤنث. أرسل معرّفه فقط بعد Publish. لا ترسل API Key. الإجابات الجاهزة لقُمَيرة تستخدم صوتها المحدد أصلًا؛ المحادثة المباشرة تحتاج Agent النسائي.

ما لم يُنجز:
- اختبار حقيقي للمقاطعة الصوتية بعد تغيير إعدادات حسابك.
- أداة بحث مباشر داخل Agent. مكتبة المعرفة لا تكفي للبحث في الإنترنت.
- مجموعة تسجيلات مشتركة على GitHub. التجهيز المتاح اختياري ومحدود بأهم ثماني إجابات والتعريف للقسم الحالي، ويُحفظ محليًا على الجهاز.
